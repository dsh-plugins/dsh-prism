# A conversa

Descreva o resultado no cliente Web. Por exemplo, peça uma revisão do checklist de lançamento de um aplicativo móvel e uma lista dos testes que faltam. O Prism encontra os projetos pelo registro.

## Escolher o modelo

O seletor fica no campo de mensagem, à esquerda do botão de envio. Ele apresenta as capacidades de cada modelo L1. A escolha vale para os próximos turnos e mantém o rascunho. Enter envia; Shift+Enter insere uma linha.

## Acompanhar uma tarefa

O trabalho delegado aparece em um cartão recolhido. Abra-o para ver o estado e as etapas. Se a prioridade mudar, escreva na mesma conversa. O agente de planejamento pode informar o progresso enquanto outras etapas continuam.

![Cliente Web em chinês com checklist de lançamento, tarefa concluída e seletor de modelo.](/screens/web-task.png)

## Ler a sessão

Abra o histórico de uma tarefa no modo de leitura para ver o diálogo e os nomes das ferramentas. Atualize para buscar registros recentes. A consulta verifica a titularidade sem obter o bloqueio de escrita. Janelas do mesmo proprietário DSH compartilham a conversa; identidades de mensagens têm históricos próprios.
