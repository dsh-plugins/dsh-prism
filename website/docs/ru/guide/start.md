# Быстрый старт

Начните с одного компьютера и одного проекта. После первого диалога можно подключить ещё одно устройство или бота.

## Установка и запуск

Установите Git, npm и Node.js версии 24.9 или новее. Скрипт checkout загрузит версии пяти плагинов, соответствующие основному репозиторию. Выполните команды в терминале.

Основной репозиторий и документация публичны. Для запуска нужен доступ Git на чтение ко всем пяти закрытым репозиториям плагинов. До checkout настройте аутентификацию Git с разрешённой учётной записью. Продолжайте работу в созданном каталоге `runtime/`.

```sh
git clone https://github.com/dsh-plugins/dsh-prism.git
cd dsh-prism
node scripts/checkout.mjs
cd runtime
npm ci
npm run build
cp prism.example.json prism.config.json
npm start -- prism.config.json --host 127.0.0.1 --port 3080 --no-open
```

## Модель и проект

В примере используется провайдер DSH `deepseek-official`. Настройте учётные данные в DSH или задайте `DEEPSEEK_API_KEY` в окружении процесса. Укажите каталог проекта в `registry.projects[].workspace`. Относительный локальный путь отсчитывается от файла конфигурации.

`orchestrator.defaultProjectId` должен указывать на проект, доступный владельцу веб-сеанса. Пример разрешает чтение и поиск. После изменения JSON перезапустите службу.

## Первый диалог

Откройте ссылку для входа, которую вывел DSH. Браузер обменяет токен на cookie и откроет `/prism`. Спросите о доступных проектах, затем поручите конкретную задачу. При ошибке обработки проверьте учётные данные, идентификатор модели и права на проект по умолчанию.
