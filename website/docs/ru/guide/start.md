# Быстрый старт

С Prism не нужно переключаться между папками проектов вручную: вы пишете один запрос в общем чате, а он проверяет сразу несколько проектов и собирает итоговый ответ. Иллюстрированные руководства доступны на [английском](/guide/start) и [китайском](/zh/guide/start) языках (DeepSeek Harness `0.2.3-alpha.2`).

## 1. Установите пять плагинов

В DSH откройте **Plugins → Add plugin** и установите пакеты из таблицы по порядку. После каждого пакета нажимайте **Enable now**, прежде чем переходить к следующему:

| Порядок | Пакет и версия |
| --- | --- |
| 1 | `@dsh-prism/dsh-workspace-registry@0.1.2` |
| 2 | `@dsh-prism/dsh-orchestrator@0.2.0` |
| 3 | `@dsh-prism/dsh-mesh-node@0.2.1` |
| 4 | `@dsh-prism/dsh-im-gateway@0.2.0` |
| 5 | `@dsh-prism/dsh-concierge-ui@0.2.0` |

Оркестратор запускается после включения Mesh.

> [!TIP]
> Если пункт **Prism** не появился в боковой панели сразу после включения всех пяти плагинов, обновите вкладку браузера.

### Долговременная память и триггеры событий (необязательно) {#optional-plugins}

После включения пяти основных плагинов добавьте нужные пакеты в том же профиле DSH. Память позволяет сохранять сведения и прикреплять медиафайлы. Триггеры добавляют напоминания по расписанию и внешние события.

В разделе **Plugins → Add plugin** введите точное имя пакета с версией и нажмите **Enable now**. Для профиля `web` можно также использовать следующие команды.

```sh
dsh plugin --profile web add "@dsh-prism/dsh-memory@0.2.0"
dsh plugin --profile web add "@dsh-prism/dsh-triggers@0.2.0"
```

## 2. Подключите модель и добавьте проекты

1. Откройте **Settings → Models → Add model provider → Custom model API**, выберите **OpenAI Responses**, укажите адрес сервиса, API-ключ и идентификатор модели `deepseek-v4.1-flash`, затем выберите эту модель в чате DSH.
2. Нажмите **Add workspace** на боковой панели и откройте папки проектов (например, `harbor-books` и `lantern-cafe`). Prism автоматически определяет локальные области DSH по их названиям.
3. При желании в **Settings → Prism/Configuration** можно отдельно настроить модели и подсказки для каждого этапа (**L1 Диалог**, **L2 Планирование**, **L3 Выполнение**).

## 3. Отправьте запрос и проверьте результат

Откройте **Prism** в боковой панели и попросите проверить время начала, место проведения и ответственного в `README.md` обоих проектов. В ленте появятся компактные карточки задач, а по завершении Prism пришлёт готовую сводку.

Если захочется убедиться, какие именно файлы были прочитаны, вернитесь через **DeepSeek Harness** сверху и откройте историю только для чтения в нужной рабочей области.
