# Быстрый старт

Для проверки Prism подойдут две папки проектов на одном компьютере. Пошаговое руководство со снимками экрана показывает весь процесс в DeepSeek Harness 0.2.3-alpha.2. [Руководство на английском](/guide/start) · [Руководство на китайском](/zh/guide/start)

1. Откройте менеджер плагинов DSH. По очереди вводите названия npm-пакетов с версиями из таблицы. Установите и включите каждый плагин перед добавлением следующего.
2. В настройках моделей добавьте поставщика с собственным API. Выберите OpenAI Responses, введите адрес сервиса, ключ API и идентификатор модели `deepseek-v4.1-flash`.
3. Откройте обе папки как рабочие пространства DSH. В чате DSH выберите добавленного поставщика и модель.
4. Откройте **Prism** на боковой панели DSH. Попросите создать по задаче для каждого рабочего пространства и найти в его README время начала мероприятия, место и имя ответственного.
5. На карточке задачи видны время и состояние. Вернитесь в DSH по ссылке **DeepSeek Harness** и в каждом рабочем пространстве откройте историю выполнения в режиме чтения. Сверьте ответ с обоими файлами README.
