# Быстрый старт

С Prism не нужно переключаться между папками проектов вручную: вы пишете один запрос в общем чате, а он проверяет сразу несколько проектов и собирает итоговый ответ. Иллюстрированные руководства доступны на [английском](/guide/start) и [китайском](/zh/guide/start) языках (DeepSeek Harness `0.2.3-alpha.2`).

## 1. Установите семь обязательных плагинов

В DSH откройте **Plugins → Add plugin** и установите пакеты из таблицы по порядку. После каждого пакета нажимайте **Enable now**, прежде чем переходить к следующему:

| Порядок | Пакет и версия |
| --- | --- |
| 1 | `@dsh-prism/dsh-workspace-registry@0.1.2` |
| 2 | `@dsh-prism/dsh-orchestrator@0.2.1` |
| 3 | `@dsh-prism/dsh-mesh-node@0.2.2` |
| 4 | `@dsh-prism/dsh-im-gateway@0.2.0` |
| 5 | `@dsh-prism/dsh-concierge-ui@0.2.2` |
| 6 | `@dsh-prism/dsh-memory@0.3.1` |
| 7 | `@dsh-prism/dsh-triggers@0.2.1` |

Оркестратор запускается после включения Mesh.

> [!TIP]
> Если пункт **Prism** не появился в боковой панели сразу после включения всех семи плагинов, обновите вкладку браузера.

### Долговременная память и триггеры событий {#optional-plugins}

Память позволяет сохранять сведения и прикреплять медиафайлы. Триггеры добавляют напоминания по расписанию и внешние события.

В разделе **Settings → Prism/Memory** выберите **Remote API**. В поля `BASE_URL` и `API_KEY` подставьте значения переменных окружения `EMBEDDINGS_BASE_URL` и `EMBEDDINGS_API_KEY` соответственно, а в поле `MODEL_ID` введите `BAAI/bge-large-zh-v1.5`. Подтвердите подключение и дождитесь инициализации. После неё станут доступны инструменты памяти. При следующих запусках DSH Prism автоматически загрузит привязку.

## 2. Подключите модель и добавьте проекты

1. Откройте **Settings → Models → Add model provider → Custom model API** и выберите **OpenAI Responses**. Укажите значения переменных окружения `BASE_URL` и `API_KEY`, затем добавьте `deepseek-v4.1-flash` как идентификатор модели.
2. Откройте настройки провайдера и включите **Reasoning levels** в **Customized settings → Model options**. Сохраните уровень `high` со значением API `high`. В чате DSH выберите модель, затем **Effort → High**. Оркестратор Prism `0.2.1` передаёт в сеансы Prism только провайдера и модель, поэтому выбор уровня рассуждения в чате DSH на них не распространяется.
3. Нажмите **Add workspace** на боковой панели и откройте папки проектов, например `harbor-books` и `lantern-cafe`. Prism находит рабочие области по их названиям.
4. В **Settings → Prism/Configuration** используйте одинаковые описание и подсказку для каждой модели на всех этапах (**L1 Диалог**, **L2 Планирование**, **L3 Выполнение**). См. [описания и подсказки моделей](./model-metadata.md). Настройте `gpt-6.2-sol`, если эта модель уже доступна в DSH через другого провайдера.

## 3. Отправьте запрос и проверьте результат

Откройте **Prism** в боковой панели и попросите проверить время начала, место проведения и ответственного в `README.md` обоих проектов. В ленте появятся компактные карточки задач, а по завершении Prism пришлёт готовую сводку.

Если захочется убедиться, какие именно файлы были прочитаны, вернитесь через **DeepSeek Harness** сверху и откройте историю только для чтения в нужной рабочей области.
