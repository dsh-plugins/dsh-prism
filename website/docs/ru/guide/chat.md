# Работа с чатом

Нажмите **Prism** на боковой панели DSH, чтобы открыть чат. Выбирать рабочую область или помнить пути к папкам не нужно — просто опишите задачу и при необходимости назовите проект.

## Смена модели в любой момент

Меню выбора модели рядом с кнопкой **Send** показывает доступные модели и их сильные стороны. Переключение действует со следующего сообщения и сохраняет текущий черновик. **Enter** отправляет сообщение, **Shift+Enter** переносит строку.

## Прогресс без лишнего шума

Каждая делегированная задача отображается в виде сворачиваемой карточки с заголовком, статусом и временем. Пока задачи выполняются в фоне, можно продолжать диалог — Prism ответит, как только всё будет готово.

## Просмотр деталей при необходимости

Чтобы проверить, какие файлы читал агент, нажмите **DeepSeek Harness** сверху и раскройте нужный проект в **Workspaces**:
- **棱镜**: основной диалог
- **棱镜 L2**: планирование по проекту
- **棱镜 L3**: выполнение и чтение файлов

Вся история открывается только для чтения. Чтобы вернуться в чат, снова нажмите **Prism** на боковой панели. [Иллюстрированное руководство (EN)](/guide/chat) · [На китайском](/zh/guide/chat)
