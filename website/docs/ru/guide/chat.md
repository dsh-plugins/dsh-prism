# Работа с чатом

Опишите ожидаемый результат в браузере. Например, попросите проверить список действий перед выпуском мобильного приложения и найти недостающие проверки. Проекты подбираются через реестр.

## Выбор модели

Список моделей расположен в поле ввода слева от кнопки отправки. В нём указаны возможности каждой модели L1. Выбор действует со следующего хода и сохраняет черновик. Enter отправляет сообщение, Shift+Enter добавляет строку.

## Ход задачи

Для переданной работы появляется свёрнутая карточка. Раскройте её, чтобы увидеть состояние и этапы. Уточните приоритеты в том же диалоге. Планировщик может сообщать о ходе работ до завершения остальных этапов.

![Веб-клиент на китайском с контрольным списком выпуска, завершённой задачей и выбором модели.](/screens/web-task.png)

## Просмотр сеанса

Откройте историю задачи в режиме чтения, чтобы посмотреть записанные сообщения и имена инструментов. Обновление подгружает новые записи. Проверяются права владельца, блокировка записи не требуется. Окна браузера одного владельца DSH используют общий диалог, а у каналов мессенджеров свои истории.
