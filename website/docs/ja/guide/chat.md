# 会話の使い方

Web クライアントで欲しい結果を伝えます。例えば「モバイル版の公開前チェックリストを点検し、足りない検証項目を挙げて」と依頼できます。プロジェクトは登録情報から選ばれます。

## 対話モデルを選ぶ

入力欄の右下、送信ボタンの左にモデル選択があります。各 L1 モデルの説明を読んで選ぶと、下書きを保ったまま次のターンから切り替わります。Enter で送信、Shift+Enter で改行します。

## タスクを追跡する

委譲された作業は折りたたまれたタスクカードに表示されます。開くと状態と実行ステップを確認できます。優先順位が変わったら同じ会話で伝えてください。他のステップを実行中でも計画担当から途中経過を受け取れます。

![中国語の Web 画面に表示された公開チェックリスト、完了タスク、モデル選択。](/screens/web-task.png)

## セッションを読む

タスクから読み取り専用のセッションを開くと、記録された会話とツール名を確認できます。更新すると新しい記録を取得します。閲覧時は所有権を確認し、書き込みロックは取得しません。同一所有者の Web ウィンドウは会話を共有し、メッセージアプリの履歴は別に保存されます。
