# 会話の使い方

DSH サイドバーの **Prism** をクリックしてチャットを開きます。ワークスペースを切り替えたりフォルダーのパスを覚えたりする必要はなく、やりたいことと必要に応じてプロジェクト名を伝えるだけです。

## 会話モデルをいつでも切り替え

入力欄の **Send** 横にあるモデルメニューから、利用可能な会話モデルとそれぞれの特徴を確認できます。切り替えは次のメッセージから有効になり、入力中の下書きは保持されます。**Enter** で送信、**Shift+Enter** で改行です。

[メモリープラグイン](./start.md#optional-plugins)を有効にすると、入力欄のプラスボタンで画像や動画を添付できます。アップロードに失敗したファイルは再試行または削除できます。

Prism は DSH の外観設定に従います。システムモードでは、デバイスのライト・ダーク切り替えがページにも反映されます。

同じ DSH プロファイルでは、Web と承認済みの個別チャットが会話を共有します。回答と進捗は依頼元のチャネルに届きます。プロジェクトの権限は依頼者ごとに確認します。

## 邪魔にならず進捗を把握

依頼したタスクはタイトル・状態・時刻付きの折りたたみカードとして表示されます。裏側で処理が進んでいる間も会話を続けられ、完了すると Prism が結果を返信します。

## 必要なときだけ裏側の記録を確認

参照されたファイルや手順を確かめたいときは、上部の **DeepSeek Harness** をクリックして **Workspaces** 内のプロジェクトを展開します。
- **棱镜**：メインの会話
- **棱镜 L2**：プロジェクトの計画
- **棱镜 L3**：具体的な実行とファイル読み取り

履歴はすべて読み取り専用です。サイドバーの **Prism** を押せばいつでもチャットに戻れます。[英語の画像ガイド](/guide/chat) · [中国語の画像ガイド](/zh/guide/chat)
