# 会話の使い方

Web クライアントで欲しい結果を伝えます。例えば「モバイル版の公開前チェックリストを点検し、足りない検証項目を挙げて」と依頼できます。プロジェクトは登録情報から選ばれます。

## 対話モデルを選ぶ

入力欄の右下、送信ボタンの左にモデル選択があります。各 L1 モデルの説明を読んで選ぶと、下書きを保ったまま次のターンから切り替わります。Enter で送信、Shift+Enter で改行します。

## タスクを追跡する

委譲したタスクのカードには、タイトル、時刻、状態が表示されます。結果がそろうと、Prism は同じ会話に回答を返せます。

## セッションを読む

**DeepSeek Harness** で DSH に戻り、対象のワークスペースのサイドバーから読み取り専用履歴を開きます。会話は `棱镜`、計画は `棱镜 L2`、実行は `棱镜 L3` という名前です。L3 の履歴には呼び出したツールと読み取ったファイルが記録されます。
