# モデルの説明とプロンプト

**Settings → Prism/Configuration** で、同じモデルを有効にした層（L1、L2、L3）には、同じ説明とプロンプトを設定します。上位エージェントは説明をもとにサブエージェントを選びます。プロンプトはモデルの作業全般に適用される方針を設定します。

## `deepseek-v4.1-flash`

DSH のモデル選択メニューで推論レベルを **High**（`high`）に設定します。Prism オーケストレーター `0.2.1` がセッションに渡すのはプロバイダーとモデル ID だけなので、Prism の推論レベルはプロバイダーの既定値に従います。[クイックスタート](./start.md)

### モデルの説明 {#deepseek-description}

```text
能力：標準的な能力を備え、範囲が明確な個別タスクをこなせます。効率は中〜高程度です（応答は速いものの、1 ターンあたりのトークン利用効率は低めです）。複雑な場面では考えすぎる傾向があります。用途：単一ファイルの修正、既定のテンプレートに沿った一括書き換え、目的を絞った検索と情報の取りまとめ、小規模なコードレビュー。特記事項：DSH（DeepSeek Harness）プラグイン制作向けの専用モデルです。適用条件：タスクの目標と受け入れ基準が明確で、モジュール間の調整を必要とせず、効率が求められる場合に使います。メインエージェントが DeepSeek 以外のモデルを使っている場合、DeepSeek Harness プラグインの実装にはこのモデルを優先します。
```

### モデルのプロンプト {#deepseek-prompt}

```text
コストは気にせず、最大限の効率でタスクを完了してください。1 ターンで複数のツールの使用や複数の指示の実行を**並列化**することを優先し、ツールを**1 回だけ呼び出す**ことや指示を 1 件だけ実行することは、できる限り避けてください。
```

## `gpt-6.2-sol`

別途設定した DSH プロバイダー経由で `gpt-6.2-sol` を使用できる場合は、以下の値を使います。

### モデルの説明 {#gpt-description}

```text
能力：論理的推論と数学に秀でています。バックエンドの能力にも秀でています。全体を見通す力とプロジェクトのアーキテクチャ設計力は極めて弱く、効率は標準的です。用途：範囲を絞ったコードレビュー、厳密な論理や複雑な数学を要する問題の解決。適用条件：小範囲の論理的なコードレビューを並行して進めるときや、厳密な論理や複雑な数学を要する問題を解くときに使います。
```

### モデルのプロンプト {#gpt-prompt}

```text
正確で自然な言葉を使い、会話での回答、文書、コードコメントの文体を厳格に管理してください。実行予定の操作や確認済みの技術的な結論を端的に述べてください。何をしないか、何を変更せずに残すか、結果をどう分割して分類するかは**補足説明しないでください**。資料を読んだ過程や自分がどう考えたかは述べないでください。冒頭で挨拶したり、相手を褒めたり、質問を言い直したりしないでください。末尾に中身のないまとめ、スローガン、対応範囲についての免責事項を付けないでください。
```
