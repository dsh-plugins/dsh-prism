# La conversación

Describe en la web el resultado que necesitas. Por ejemplo, pide que revisen una lista de publicación móvil y señalen las pruebas pendientes. El sistema localiza el proyecto mediante el registro.

## Elegir el modelo

El selector está dentro del cuadro de escritura, a la izquierda de Enviar. Muestra las capacidades de cada modelo L1. La selección afecta a los turnos siguientes y conserva el borrador. Intro envía y Mayús+Intro añade una línea.

## Seguir una tarea

El trabajo delegado aparece en una tarjeta plegada. Ábrela para ver el estado y los pasos. Si cambian tus prioridades, escríbelas en la misma conversación. El agente de planificación puede informar mientras otros pasos siguen ejecutándose.

![Cliente web en chino con una lista de publicación, la tarea completada y el selector de modelo.](/screens/web-task.png)

## Leer la sesión

Abre el historial de solo lectura de una tarea para consultar el diálogo y los nombres de las herramientas. Actualízalo para ver entradas nuevas. El visor comprueba la titularidad y no toma el bloqueo de escritura. Las ventanas del mismo propietario web comparten conversación; las identidades de mensajería tienen historiales independientes.
