# La conversation

Décrivez le résultat attendu dans le client Web. Demandez par exemple une revue de la liste de vérification avant la sortie d’une application mobile. Prism consulte le registre pour choisir le projet.

## Choisir le modèle

Le sélecteur se trouve dans la zone de saisie, à gauche du bouton d’envoi. Il présente les capacités des modèles L1. Votre choix s’applique aux tours suivants et conserve le brouillon. Entrée envoie, Maj+Entrée insère un saut de ligne.

## Suivre une tâche

Une carte repliée apparaît pour le travail délégué. Dépliez-la pour voir le statut et les étapes. Précisez un changement de priorité dans la même conversation. L’agent de planification peut signaler un progrès pendant l’exécution des autres étapes.

![Client Web chinois affichant une liste de vérification, sa tâche terminée et le choix du modèle.](/screens/web-task.png)

## Consulter la session

Ouvrez la vue en lecture seule d’une tâche pour consulter les échanges et les noms des outils. Actualisez-la pour charger les nouvelles entrées. La vue vérifie le propriétaire sans prendre de verrou d’écriture. Les fenêtres du même propriétaire DSH partagent la conversation ; les identités de messagerie ont leurs propres historiques.
