# La conversation

Décrivez le résultat attendu dans le client Web. Demandez par exemple une revue de la liste de vérification avant la sortie d’une application mobile. Prism consulte le registre pour choisir le projet.

## Choisir le modèle

Le sélecteur se trouve dans la zone de saisie, à gauche du bouton d’envoi. Il présente les capacités des modèles L1. Votre choix s’applique aux tours suivants et conserve le brouillon. Entrée envoie, Maj+Entrée insère un saut de ligne.

## Suivre une tâche

La carte d’une tâche déléguée affiche son titre, son heure et son état. Prism peut répondre dans la conversation dès que les résultats sont disponibles.

## Consulter la session

Revenez dans DSH avec **DeepSeek Harness**. Dans la barre latérale de chaque espace de travail, ouvrez l’historique en lecture seule. Les entrées portent les noms `棱镜` pour la conversation, `棱镜 L2` pour la planification et `棱镜 L3` pour l’exécution. L’historique L3 montre les appels d’outils et les fichiers lus.
